# VF PLUS

Динамичная Bullet Hell игра и модульный движок на **Godot**. 

Проект полностью **открытый (Open Source)**, чтобы каждый мог лично убедиться в безопасности кода, а также легко создавать свои уровни и паттерны атак. Игра построена по принципу **KISS** — всё максимально просто, понятно и разложено по полочкам.

##  Главные фишки

*  **Plug-and-Play Моддинг:** Вы можете создавать не просто уровни, а сами паттерны атак. Достаточно написать свой скрипт (например, `supermegacustomlaser.gd`), закинуть его в папку, и игра подхватит его на лету без пересборки.
*  **JSON-уровни:** Сценарии волн, спавн паттернов, в том числе катомных и настройки атак читаются из простых `.json` файлов. Написать свой уровень можно в обычном блокноте.
*  **Музыка с Newgrounds:** Укажите ID трека с Newgrounds прямо в уровне.json, и игра сама скачает его.

##  Архитектура (KISS)

Код не перегружен лишними абстракциями:
1. **Pattern Manager** — читает настройки из JSON-файла уровня и запускает нужные атаки.
2. **Папка с паттернами** — хранит изолированные файлы атак (вроде `aimed.gd` или `laser_grid.gd`). Движок полностью независим от их количества.

##  Как поиграть?

Вам **не нужно** скачивать Godot или собирать проект из исходников. 

1. Перейдите в раздел **[Releases](https://github.com/cybercore-arch/VF-plus/releases)** справа на этой странице.
2. Скачайте архив для своей операционной системы.
3. Распакуйте и запустите исполняемый файл игры.
